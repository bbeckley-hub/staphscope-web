📘 Tutorial & User Guide

⚠️ Fair usage policy: The web version accepts up to 10 FASTA files per job to ensure fair resource allocation. If you need to analyse 100+ genomes, we recommend using the command‑line version (Conda, Docker, or Singularity) – see links below.

🔧 How to use the web interface

  1. Select a pathogen from the Tools page.
  2. Upload your genome(s) – you can upload multiple FASTA files (.fasta, .fna, .fa) or a ZIP archive containing them.
  3. Optional: Enter your email – we will send you a direct link to your results when the job finishes.
  4. Choose which modules to run – uncheck any you want to skip (e.g., visualisation, lineage).
  5. Submit – you will be redirected to a progress page with live logs. You can close the browser and return later via the email link.
  6. Access results – when the job completes, you will be automatically redirected to the results page, or you can click the link in the email.

🐍 Running the command‑line version (for >10 genomes)

All pipelines are available as Conda packages, Docker images, and Singularity containers. See each tool’s GitHub repository for detailed instructions:

  • StaphScope – Conda, Docker, Singularity
  • AcinetoScope – Conda, Docker, Singularity
  • EcoliTyper – Conda
  • Kleboscope – Conda
  • PseudoScope – Conda
  • EnteroMark – Conda
  • EnteroScope – Conda

For large‑scale analyses (100+ genomes), the command‑line version is faster and does not have the 10‑file limit.
